# My Warehouse

A small inventory app built with Next.js, React and TypeScript. Browse stock items, see low-stock and out-of-stock badges, flag items for a stock check, and build a pick list with each item's location.



## What I practised

- Server and Client Components
- Props, state and React Context
- File-based routing and layouts
